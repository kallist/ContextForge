Two commands. A clearer context.

RepoBound v0.5.1 requires Node.js >=24.15 <25.

npm install -g @kallist/repobound
repobound studio

The historical @kallist/contextforge@0.5.0 package remains available but deprecated. It owns the old contextforge command; RepoBound owns repobound.
