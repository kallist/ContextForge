## Review and corrections

Development found an allocation/output-order integration bug: PIN reordered the
actual payload while the Capsule contract required preserved section/rank order.
The fix separates allocation priority from serialization order; Capsule validation
was retained. The frozen-source gate also rejected extending the public composition;
its original bytes were restored and lifecycle composition moved to a separate file.
No frozen allowlist was weakened. Generation-change races reject controlled results;
concurrent history initialization rechecks schema under its writer transaction.

Hosted validation subsequently exposed `SQLITE_BUSY` during the initial schema read:
the connection's lock timeout had been configured after that read. Native test-only
diagnostics identified the failing read. The connection now sets its bounded timeout
before any schema access, without mutating a future-version database. Real competing
process assertions are retained; final hosted results must cover the corrected commit.

Test preparation also exposed a missing dist build, cleanup ordering
for a Windows SQLite handle, and Fetch API header normalization in a Host/Fetch
Metadata test. Raw HTTP requests now exercise the actual hostile header values.
OS temporary paths are canonicalized where the system directory itself is an alias.

Privacy/security review covered path-bearing tasks, raw task hashes, source-light
storage, oversized/corrupt imported Capsules, controls and source exclusions, hostile
origins/Host/Fetch Metadata, bearer capability, traversal, strict static routes,
safe error mapping, DOM text rendering and stored XSS. Path-bearing exact source
payloads are withheld by Studio without rewriting their identity. CLI source output
retains its explicit boundary. Lexical redaction is not a general secret detector.

Remaining BLOCKING: none in local technical review. IMPORTANT: none unresolved.
Limitations: trusted local OS account, logical deletion rather than secure erasure,
bounded captured-fact coverage, no historical source restoration, no global repository
identity, and V1-only human controls. Hosted/platform/publication results must be
checked on the final commit and published artifact.

NOT TESTED: Docker, real external providers, third-party agent-host UX, long-term
million-entry history, network filesystems, adversarial same-user OS compromise,
and generalization to large external repositories. Agent success is not measured.
V0.4 is NOT STARTED.
