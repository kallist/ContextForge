# Product positioning

One sentence: See and control the repository context your coding agent works with.

30 seconds: Give ContextForge a coding task or local Git change and a declared budget. Inspect selected source and recorded drop reasons, apply explicit controls, then compare or replay before sharing the resulting repository context with an agent.

Technical: local deterministic V1 lexical/structural retrieval and hard estimator-budget packing, with source verification, source-light Capsule metadata, Explain, Coverage/Lint, human controls, semantic Diff and Replay. CLI is the complete interface; Studio is a loopback visual adapter; MCP exposes status/index/search/pack. The Skill is workflow guidance.

For developers who want inspectable repository evidence and explicit budget decisions. Not for users seeking an autonomous coding agent, bug detector, full runtime impact graph, cloud repository service or hidden-model-context viewer.

Claims: no coding-success, review-accuracy, speed or percentage-token-saving claim. A dropped candidate is not proven irrelevant. One-hop relationships are bounded evidence. No compiler, ranking or benchmark Gold changes; no V2 promotion.
